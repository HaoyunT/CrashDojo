# Archived development configuration

`ccdiff.evaluation.contract`. Its paired-endpoint and emergence measurements
belong to an earlier development protocol. They do not define the reported
main-table collision, off-road or same-scene distribution metrics.

This directory is not an experiment entrypoint. The active suite entrypoints
and external runtime prerequisites are listed in `docs/EVALUATION.md`.
